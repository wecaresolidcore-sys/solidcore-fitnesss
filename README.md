# Solidcore Fitness
Expo React Native starter for Solidcore Fitness.

Planned production features:
- Member/Admin authentication
- Member management and membership expiry
- Membership plans based on the gym fee structure
- Workout plans
- Secure AI-assisted diet plans
- Attendance, notices and progress
- Android + iPhone
- No in-app payments

This starter contains no passwords, API keys, or production secrets.
